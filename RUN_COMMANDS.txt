===============================================
INDUSLINK MOBILE APP - RUN COMMANDS
===============================================

STEP 1: Navigate to the mobile directory
----------------------------------------
cd induslink-mobile


STEP 2: Start the Expo development server
----------------------------------------
npm start

This will:
- Start the Metro bundler
- Display a QR code
- Show development options


STEP 3: Connect with Expo Go App
----------------------------------------

Android:
1. Install "Expo Go" app from Google Play Store
2. Open Expo Go app
3. Scan the QR code shown in terminal
   OR press 'a' in terminal to open on Android emulator

iOS:
1. Install "Expo Go" app from App Store  
2. Open Camera app
3. Scan the QR code shown in terminal
   OR press 'i' in terminal to open on iOS simulator


STEP 4: Alternative Commands
----------------------------------------
# For Android specific
npm run android

# For iOS specific (requires macOS)
npm run ios

# For web browser
npm run web
