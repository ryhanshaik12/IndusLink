===============================================
HOW TO START INDUSLINK MOBILE APP
===============================================

IMPORTANT: Close the current Expo server if it's running!

Then run these commands:

STEP 1: Navigate to mobile directory
------------------------------------
cd induslink-mobile


STEP 2: Start Expo server
------------------------------------
npm start


STEP 3: Scan QR Code
------------------------------------
Open Expo Go app on your phone and scan the QR code


WHAT YOU'LL SEE:
===============================================
✅ Marketplace - Browse industrial materials
✅ Cart - View your shopping cart
✅ Orders - Track your orders  
✅ Profile - Account info and support
✅ Bottom tab navigation


FEATURES:
===============================================
🔐 Password-based authentication
📷 Image upload from device (for sellers)
🛒 Shopping cart functionality
📦 Order tracking
👤 User profile
🏪 Browse marketplace


TROUBLESHOOTING:
===============================================
If you see "Open App.js":
1. Press 'r' in terminal to reload
2. Shake your phone and tap "Reload"
3. Restart Expo: Ctrl+C then npm start

If app crashes:
1. Check all files are in correct folders
2. Run: cd induslink-mobile && npm install
3. Run: npm start again
